# Haider School Staff Attendance

Website preview for **Haider Model Computerized Public Boys School, Haiderabad Thall** (PEF code: 9-BHK-0002).

## Current status
This repository currently contains a static UI preview only. It is **not a production attendance system** and has no real authentication, database, attendance persistence, or export feature. Do not enter real staff/student information.

## Before real school use
1. An authorized school administrator must create/own the cloud project (for example Firebase).
2. Configure Firebase Authentication and Firestore with restrictive security rules and admin/staff roles.
3. Add the approved web configuration to the app; never commit service-account private keys or credentials.
4. Test access controls and attendance workflows with dummy accounts and dummy records.
5. Enable hosting and verify the deployed URL before using it operationally.

GitHub Pages serves static files; it does not provide secure user authentication or a private database by itself.
